# 论文第 4.2 节候选表述

为检验防御资源对攻击重点转移的响应，保持六资产合成网络的拓扑、参数与防御容量不变，将时域等分为十二段。API 网关和 Web 应用的攻击强度在第 5 段由 (0.40,0.20) 交换为 (0.20,0.40)，第 9 段恢复原分配；逐段攻击投入均为 0.60，努力成本率均为 0.10。重规划方案在两个事件点使用实际受损状态，并以当期观测到的分配作为剩余时域的预测；固定方案继续执行初始防御计划。

在第 5 段起始状态的匹配对照中，攻击重点转向 Web 后，首段 API 隔离下降 0.02252、恢复增加 0.02760，Web 的两项行动反向调整，两入口总占用均略增。这不是即时单向转移；但在同一预测计划的第 6—8 段，API 资源减少、Web 资源增加，第 8 段变化分别为 −0.10029 和 +0.08497。第 9 段的同状态对照也显示入口间重分配，但幅度较小。

在相同实际攻击下，重规划使综合损失由 7.922288 降至 7.904890（下降 0.2196%）。该净收益来自行动成本节省，累计加权受损损失反增 0.01255。Web 终点受损比例降低 0.877 个百分点，而数据库和全网加权终点受损比例分别升高 0.091 和 0.065 个百分点。结果支持此工况下资源配置对攻击位置有响应，但不支持所有资产安全状态改善，也不构成全局最优或双方均衡证据。
