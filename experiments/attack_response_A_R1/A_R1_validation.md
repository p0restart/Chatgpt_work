## 复现

解压到独立目录，在 `attack_response_A_R1` 中运行（Python 与依赖版本见 `A_R1_run_config.json`）：

```powershell
python A_R1_reproduce.py --output ./fresh_run
python A_R1_plot.py --root ./fresh_run
```

随包 `original_A/` 是只读复现输入，不依赖原仓库；驱动支持 `--original-a` 指向另一个相同已验证的 A 目录。输入清单、代码版本和 SHA-256 见运行配置。新数值运行日志为 `A_R1_execution.log`，四份计划逐起点详情在 `S1_audit/A_optimizer_trace.json`，全部执行状态在 `A_R1_state_trajectories.csv`；`A_R1_S1_plans.csv` 保留 S1 完整规划（包括未执行尾部）。仓库回归命令：`python -m pytest -q -p no:cacheprovider`。
