## 三项工作的直接结论

1. **防御配置有可辨认差异。**每组最大隔离分量差0.01654–0.04199，最大恢复差0.01534–0.03494；平均每槽加权绝对差之和占容量1.703%–10.844%。该指标同时含重新配置与总用量变化，不能直接称为搬移比例。以seed11/B1.2第1槽（时间5/3至10/3）为例，节点1的隔离从F的0.262232增至G的0.300560、恢复从0.292752增至0.317004；节点0隔离从0.187969降至0.157432、恢复从0.317137降至0.290666。这里不只是投入总量变化，确有入口之间的资源转移。
2. **攻击响应存在依赖，变化幅度有限。**固定防御后，保存的两条三起点局部响应有不同投入，其自身响应相对另一条响应的攻击收益改善为0.000221–0.001874。入口集合始终是0、1；仅2/54个槽的最大攻击投入节点在两种防御之间变化，均是seed33的末槽、两个入口投入接近时的细小排序交叉，不能称为实质改换攻击目标。公共a0为每槽两入口各0.4；aG、aF分别由各自防御诱导。主报告和CSV严格区分公共攻击、各自响应及交叉响应。
3. **可见战略依赖不等于收益增量很大。**各自响应下G相对F防御损失降低0.02896%–0.28608%，中位数0.14634%；9/9低于原1%工程描述门槛。公共a0下F更好0.01659%–0.09414%。PMP/KKT解释双方边际的联系，不能证明上述差异有全局最优或Nash含义。当前结论限定于九组指定合成实例、K6及保存局部候选。
