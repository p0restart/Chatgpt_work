# D7 图件约定

沿用项目Python/Matplotlib工作流。目标为EI会议待审稿，未指定会议版式；主图宽约180毫米，正文文字至少7pt，PNG预览+SVG/PDF矢量导出。全部绘图值来自D7新网络输出；不复制旧拓扑主图。确定性单场景，不绘制无意义置信区间或显著性标记。

1. 拓扑图：回答哪些资产可被直接攻击、隔离影响哪些出边；8条固定边与q数据库位置必须完整。边只是预设安全关联，不暗示实测漏洞。
2. 流程图：回答状态/参数如何生成实际行动；明确内部预测与外部公共执行攻击两条路径。
3. 行动图：B1.2的两个6×6热图展示全部资产全部时段的隔离和恢复；共享0–1归一化尺度，不隐藏零隔离。
4. 比较图：展示三预算、两评价协议的成对损失差。零线可见，纵轴标明差值而非原总损失，绝对总损失在主表完整给出；协议之间不作纯动作因果差解释。
5. 执行图：主预算E0/E1下数据库受损差轨迹与认证服务实际恢复，P/G/R一致配色/线型；差轨迹以P为参照并明确标注，原状态与全量行动另表保留。事件和更新时点明确。

可比面板检查最终绘图区尺寸与边界对齐，保留alignment.json；导出后执行字体及碰撞检查并查看渲染图。若自动检查对有意重叠数据线报警，逐条说明，不删除真实数据来消除报警。图1/2无统计面板比较，采用单画布示意。图3/4/5为quantitative grid。数据、脚本与图件同包保存。
