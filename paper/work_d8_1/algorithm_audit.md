# D8-1 算法审计：数学定义、伪代码与实现

2026-11-14。审计对象为本版式(1)–(9)、算法1–2、D7实际执行源码及其保存结果。此为作者侧实现核对，不是外部独立理论审查。原核心代码未修改，未新调用求解器。

## 1. 数学问题与实际计算

连续开环理论基准为式(4)的双方单方偏离不等式。实际程序将控制限制在K=6分段常值空间：防御向量每区间先s后r，共72维；攻击向量只保留两个入口，共12维。每次剩余重规划K'=3、2、1，防御维数36、24、12，攻击维数6、4、2。控制区间长度固定为5/3，T'依次为5、10/3、5/3。

防御最小化离散积分J_D，攻击最小化−J_A；求解器只返回局部数值响应，不等于实现理论argmin/argmax的全局解。RK4对状态与累计目标积分，并同步求离散RK4映射对控制的灵敏度；连续PMP/KKT只解释边际，不是实际前向—后向伴随求解步骤。已发现偏离量按式(6)取非负改善，不是未知全局偏离的上界。投影残差在当前完整策略对上计算。

## 2. 算法1完整伪代码

```text
算法1：基于交替最佳响应的攻防策略求解算法
输入：模型参数Θ、当前状态x、剩余时域T'、K'个控制区间；
      逐区间可行集合、预登记种子、主初始化计划；H=48。
输出：逐资产逐区间攻击/隔离/恢复、状态、资源使用、双方收益、诊断。

数值响应(player, 固定对手, 当前本方计划, 起点数):
    建立本方决策向量、箱约束及逐区间线性容量约束
    初值为当前、零、按登记种子产生并缩放的可行随机计划
    按起点数取前若干个；交替阶段只取当前计划
    对每个初值调用SLSQP(maxiter=300, ftol=10^-10)
        每次目标/梯度评价：用RK4积分状态与累计目标
        同步微分离散RK4映射，计算目标对本方控制的灵敏度
    保存全部初值、返回控制、退出码、可行性与残差
    以当前计划为基准，接受可行且目标不劣的最佳返回值
    正常退出另外检查，不能用“已接受”替代“成功退出”

对完整博弈的{主路径, 全零, 可行随机}三条初始化路径分别执行：
    初始化(a,u)，其中u=(s,r)
    对m=0,...,40：
        固定同一个当前(a,u)，分别求防御响应d与攻击响应b（各1起点）
        计算已发现改善、当前点投影残差、响应距离与退出状态
        若全部停止门槛通过：保存当前(a,u)，结束本路径
        若m=40仍不通过：保存未通过状态，不再更新
        否则u←d；在新防御u下另求攻击响应a（1起点），继续检查
保留预登记主路径作为输出，不按收益筛选路径
比较三路径控制差并检查全部登记优化调用成功
在同一主策略对上，H=48与H=96分别作双方三起点偏离审计
另在固定控制下以H=48/96/192复算状态、累计目标和成本分项
检查状态范围、逐区间容量与控制可行性
若非有限值、积分异常、优化或诊断失败：保存诊断，标记失败并停止依赖步骤
否则导出a/s/r、各区间资源消耗、累计收益和数值诊断
```

## 3. 三层初始化与真正的停止顺序

|层次|具体设置|调用与作用|不可误写|
|---|---|---|---|
|交替阶段当前策略|strict_solve中observed_gaps(...starts=1)，随后顺序攻击response(...starts=1)|先固定同一完整策略对分别检查双方，再把防御更新为响应，在新防御下另求攻击|不是每一轮都运行三起点；不把旧攻击/新防御混合为一次双方审计|
|完整博弈三路径|Run.game的warm、zero、random；离线warm=initial_controls(Uniform)，滚动warm=上一计划尾段|每路径各自完整交替；主路径始终warm，控制差≤1e-3|不根据收益挑选最有利的路径；三路径不是三个独立实验样本|
|最终响应审计|pair_audit/observed_gaps在选定完整策略对上，H48/H96各作双方当前/零/随机三起点|在同一固定对手下寻找仍可发现的单方改善|不是重新选择一个G策略替换主路径，也不是证明全局gap≤阈值|
|F/R固定对手|Run.unilateral三起点及H48/H96审计|F固定a0；R固定上一观测攻击的延续预测，只优化D|不能把R写成重新求双方博弈|
|F攻击响应/E1生成|Run.unilateral(player=A,strong=True)，三起点后12起点与入口稀疏初值检查|固定F或P防御，最大化J_A后冻结；实际取selected最终candidate|不是最大化J_D；过程初值返回控制不是最终冻结攻击|

strict_solve执行iteration=0..40。未通过且iteration<40时，程序才计算下一对策略；iteration=40只检查、保存并退出。完整阶段还检查三路径最终passed、全部登记优化尝试success与主策略对H48/H96审计。没有阻尼、没有Stackelberg承诺顺序。local_best_response的accepted仅依据可行且目标不劣，正常退出success另行检查，二者不能混为一个条件。

原始求解器异常不会自动产生一条成功回退轨迹：非法输入、非有限数值、状态异常可能抛出异常，由运行编排保存FAILED；未通过质量门槛则中止依赖步骤或轨迹。不保证每一种异常都具有完整最终诊断，不能把“应保存诊断”的伪代码抽象误写成所有中断均已正常结束。

## 4. 算法2完整伪代码

```text
算法2：攻击参数扰动下的滚动防御行动重规划算法
输入：离线G计划、事件τ=5、更新后的α1=0.50；
      重规划时刻{5,20/3,25/3}；预先固定的公共执行攻击条件E0或E1。
输出：P/G/R的实际防御行动、实际状态及事件前/后/全时域分项损失。

执行离线G计划前三个控制区间，获得共同历史状态x(5)
仅更新入口v1的攻击效率，其他参数不变
生成并冻结事件后实际攻击：
    E0：两个入口均为0.4
    E1：固定P尾段防御，最大化攻击者JA得到局部响应，再冻结
        攻击生成采用三起点、12起点和入口稀疏初值检查
对方法P/G/R分别从共同x(5)开始：
    warm←离线计划剩余部分
    在每次更新时刻tj：观测当前实际状态，使用更新后的参数
        P：继续取原计划对应区间的防御行动
        G：以warm为主路径，按算法1重求剩余攻防计划，取得预测攻击与防御
        R：将上一已观测区间攻击延续到剩余时域，固定该预测，
           用当前/零/随机三起点仅优化防御，并作H=48/96响应检查
        提取本次防御计划首区间的s与r
        用冻结的公共实际攻击a_exec及首区间防御推进实际状态
        保存实际动作与状态；warm←本次计划删除已执行首区间
        若数值诊断失败：保存证据并停止，不将回退计划计为成功重规划
    拼接共同历史与实际防御，在相同实际攻击下累计损失
    以H=48/96/192复算，核对公共攻击、共同历史、连续性及容量
比较相同预算、相同事件和相同实际攻击下的方法
```
