## 可能影响终稿的几个问题

1. 既有D7结果显示G/F收益差通常只有1e-4至1e-3；不能使用“显著提升”“明显优于非博弈方法”等措辞。
2. G/R收益的相对排序随E0/E1改变，第四章滚动重规划只作为补充验证，不提升为与ABR-DAD并列的核心创新。
3. 本研究不证明连续开环Nash均衡存在、唯一性、控制策略全局最优或交替最佳响应全局收敛；第三章已按数值响应一致性写作。
4. 模型隔离为**源端隔离**，无出边数据库隔离为零是模型作用机制所致，不应推广为现实数据库不需要入向访问控制。
5. 文献[7]按期刊原始来源更正为“基于时机博弈的网络安全防御决策方法”（《计算机工程》2022），旧稿对应篇名与期刊不可靠。
6. 本文模型时间无现实秒数标定，数值解耗时不能直接证明可在线实时执行。
7. 排版前需统一第三章的公式引用、全文公式编号与会议模板要求；本次保留第三章原稿，不对其公式编号做越权编辑。

## 缺失G/F状态曲线的补图脚本

目录附带 `plot_gf_state_trends.py`。将D7对应的两个冻结防御计划在**同一攻击轨迹**下重新积分，导出长表CSV，必要字段为 `scenario,plan,time,x1,x2,x3,x4,x5,x6`，每个`scenario`下每个时间点均应有`plan=G`和`plan=F`两行。输入真实状态后可执行：

```bash
python plot_gf_state_trends.py figure_data/gf_states_common_attack.csv --scenario aG
```

脚本会检验两种防御共用时间网格、初态一致、状态处于[0,1]，按`q=(1,1,1,1,4,1)`计算加权均值并生成三面板曲线。当前不附带演示性状态数据，以免与实验数据混淆。
