## 二、第三章必须更清晰回答的四个问题

1. **决策变量是什么**：定义每个离散时段每一资产的源端隔离s_ik、受损恢复r_ik，以及攻击入口投入a_ik，给出防御向量长度2nK、攻击向量长度|E|K。
2. **计算的目标是什么**：防御给定a求min J_D，攻击给定u求max J_A，交替响应；非零和，不构造单一minmax鞍点。
3. **如何从模型得到行动**：给定可行计划→RK4推进状态→积分累计损失→求离散梯度→SLSQP计算防御/攻击响应→诊断→输出逐时段可执行s/r。必须说明初始化、多初值、约束、失败处理、已发现偏离不是全局证书。
4. **攻击条件突变后如何动作重规划**：t_j更新已知α、新初态x_exec(t_j)，重新规划[t_j,T]、只执行第一个控制时段；实际攻击a_exec与博弈内部预测攻击a_pred区分，下一个时段观察状态后继续。它属于滚动开环优化，不是反馈Nash。

## 三、算法1建议的正式描述（审核前需逐项对照真实实现）

```text
Algorithm 1  基于交替最佳响应的动态防御行动数值求解
Input: 网络模型Θ；初始状态x0；时域[0,T]；离散时段K；
       防御可行域U_K与攻击可行域A_K；积分精度H；
       登记的初始化集S0；最大外层迭代M；
       单方偏离、投影残差、响应距离及可行性容差。
Output: 各控制时段防御行动{(s_k,r_k)}、攻击预测{a_k}；
        受损状态轨迹、损失分解、可行性与数值诊断；或失败状态。

for (u^0,a^0) in S0:
    确认初始行动满足箱约束和逐时容量约束
    for m=0,...,M−1:
        使用RK4与离散灵敏度评估J_D(u^m,a^m)、J_A(u^m,a^m)
        u_BR ← SolveDefense(a^m; U_K, RK4, SLSQP)
        a_BR ← SolveAttack(u^m; A_K, RK4, SLSQP)
        计算已发现单方偏离ΔD_hat、ΔA_hat、投影残差与响应距离
        if 两侧单方偏离/残差/距离达标且约束可行、优化器正常退出:
            保存(u^m,a^m)及完整诊断；break
        if 任何数值目标非有限、状态严重越界或无可行改进响应:
            记录失败诊断；break或依预登记修复流程处理
        u^(m+1) ← u_BR
        a^(m+1) ← SolveAttack(u^(m+1); A_K, RK4, SLSQP)
    若迭代次数耗尽仍未达标：记录未收敛，不冒称均衡
保存所有初始化路径与求解日志，不按结果正负筛选证据
依预登记规则选取展示路径，对终点再作独立多起点、细积分和可行性审计
return (s_k,r_k,a_k)_{k=0}^{K−1}, 状态与损失、诊断及成功/失败标记
```

提示：这一伪代码是基于D6描述的**修订规范**，而非已完成源码一致性证明。实际程序可能对失败重启、热启动、更新次序有更精细规则，应逐项对应实际`src`及D5重规划实现修正。`SolveDefense`和`SolveAttack`作为子程序也应给出明确优化目标、参数及约束，而不只是函数名。

## 四、算法2必须补足的部分

```text
Algorithm 2  攻击参数扰动下的滚动防御行动重规划与执行仿真
Input: t=0的已规划可行防御序列；事件时刻τ=5；
       已知的新参数Θ_post；更新时刻集{5,20/3,25/3}；
       预先定义的实际攻击评价轨迹a_exec^E(t)；模型f。
Output: 每一方法的实际执行控制、状态轨迹、累计成本和时延记录。

执行公共前缀[0,τ)，得到x_exec(τ)和已发生累计成本
for 控制方法m in {P,G,R}:
    x_m(τ) ← x_exec(τ)
    for j in 事件后重规划时段:
        若m=G：用x_m(t_j)、Θ_post，运行Algorithm 1求剩余时域攻防计划
        若m=R：按前一已观测攻击持续预测未来，优化剩余时域防御计划
        若m=P：沿用事件前生成的对应时段防御行动
        从计划取首控制区间防御u_m,j并执行；不得把预测攻击当实际攻击
        通过相同公共a_exec^E(t)积分实际状态至t_(j+1)
        用实际执行控制及受损轨迹累加防御成本，保存新状态与诊断
    拼接公共前缀与事件后轨迹，核对容量约束及累计损失
同一事件后攻击评价情形E下比较P、G、R的总损失、受损分项和计算时延
```

注意：E0/E1均包含同一次α扰动；E1仅针对P旧防御计划设计，不可写作针对G或R的最坏攻击。G/R方法都根据实际状态重规划，但预测攻击机制不同，差异不能单独归因为“使用了博弈”。
