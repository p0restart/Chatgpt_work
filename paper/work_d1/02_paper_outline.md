# 全文结构与叙事主线

## 1. 论证主线

直接价值与出向传播强度可能不一致 → 用源端隔离/本地恢复模型明确两种作用路径 → 用伴随边际量解释为何不能只按静态指标排序 → 在受限开环策略类内求局部候选 → 匹配四格分析价值位置效应的传播条件依赖 → 用强基线区分动作、分时和战略训练收益 → 将反例与离散化边界纳入结论。

## 3. 术语和符号规范

|规范用语|含义及首次位置|不得混用|
|---|---|---|
|受损比例x_i|第2节实例组中的受损比例|单台主机攻击概率、二值状态、未定义风险分|
|有效传播率β_ji|第2节来源j到接收i|攻击成功概率；矩阵行列反置|
|源端隔离s_i、本地恢复r_i|第2节分别定义|接收端防护；单一混合动作|
|直接损失权重q_i、攻击状态收益权重g_i|第2节|二者自动相等；价值变化等于攻击偏好变化|
|出向传播强度Σ_kβ_ik|第2节|完整动态影响或一般中心性|
|逐时容量A/B|第2节|跨时域累计预算、各方法实际用量相等|
|开环Nash|第3节对全部允许开环偏离的理论定义|交替响应停止、Markov反馈|
|局部响应候选|第1/3节数值输出|严格均衡、全局最佳响应|
|PMP、KKT、SLSQP|第3节先给全称|把必要条件当算法已求解的连续边值系统|
|K控制槽、H每槽RK4子步|第3节|K精化与H精化互换|
|fixed_attack / common_fixed_attack|第4节共同固定攻击评价，保留各数据表字段|Fixed-trained训练方法|
|adaptive_attack|第4节冻结防御后重求攻击局部响应|在线反馈策略或Stackelberg建模|
