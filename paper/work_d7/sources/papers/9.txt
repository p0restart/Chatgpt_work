摘
要： 针对现有属性加密ABE 方案在处理复杂属性集时存在计算效率低、属性关联性利用不足等问题，文中提出了
一种基于集成学习与密文策略属性基加密（CP-ABE）结合的大模型平台访问安全控制策略。该策略包含GMDH、KNN、SVM
算法的集成学习模型，对ABE 所需属性进行特征筛选与语义聚合，构建了语义增强的属性集合。同时，采用CP-ABE 实现基
于属性集合的细粒度加密，利用分布式云节点的属性匹配实现解密。实验测试结果表明，该方案在保持安全性的前提下，加
密时间减少了32.5%，解密时间缩短了28.7%，显著优于传统的CP-ABE 方案，是一种安全有效的大模型云端交互解决方案。
关键词： 大模型平台； 密文策略属性基加密； 集成学习； 属性筛选； 访问控制； 数据安全保护

Design of access security control strategy for large model cloud platform based on the 
combination of ensemble learning and CP-ABE
Wang Jing
(China Unicom (Guangdong) New Industrialization Research Institute, Guangzhou 510700, China)
Abstract: The existing ABE schemes for attribute encryption have deficiencies such as low computational efficiency and 
insufficient use of attribute correlation when dealing with complex attribute sets. Therefore, this paper proposes an access 
security control strategy for large model platform based on the combination of ensemble learning and ciphertext-policy attribute-
based encryption (CP-ABE). In this strategy, the ensemble learning model including GMDH (group method of data handling), 
KNN (K-nearest neighbors) and SVM (support vector machine) algorithms is used to filter features and semantically aggregate the 
required attributes of ABE, so as to construct a semantically enhanced attribute sets. At the same time, CP-ABE is used to 
implement fine-grained encryption based on the attribute sets, and the attribute matching of distributed cloud nodes is used to 
achieve decryption. The experiments show that the encryption time of this scheme is shortened by 32.5%, and its decryption time 
is shortened by 28.7%. It can be seen that the proposed scheme is significantly better than the traditional CP-ABE scheme, so it 
is a secure and efficient solution for cloud-based interaction with large language models.
Keywords: large model platform; CP-ABE; ensemble learning; attribute filtering; access control; data security and protection

预处理阶段，在某智能金融风控数据集上的实验测试结
果表明，本文方法能够显著提升其加密效率。
1　相关知识
1.1　CP-ABE 属性加密
属性加密（Attribute-Based Encryption, ABE）技术允
许数据的加密和解密与属性集合相关联[9-10]。在ABE 系
统中，密文和密钥都与属性集合以及访问结构相关联，
只有当属性集合满足访问结构时，才能成功解密。ABE
主要分为密钥策略属性基加密（Key Policy Attribute - 
Based Encryption, KP-ABE）和密文策略属性基加密
（CP-ABE）。
在KP-ABE 中，用户的密钥中蕴含着访问结构即访
问策略，且密文中还对应着一系列属性集合。当且仅当
密文的属性集合满足用户密钥的访问结构时，用户才能
解密成功[11-12]。而在CP-ABE 中，用户的密钥对应着
一系列属性的集合，密文中蕴含着访问结构。当且仅当
用户的属性集合满足密文的访问结构时，用户才能解密
成功。由于CP-ABE 中数据拥有者可以根据自身需求定
义合适的访问结构，使其更适合构建云环境中数据安全
共享方案，因此本文选用CP-ABE作为基础加密技术。
在现有的研究成果中，CP-ABE 因支持细粒度访问
控制，被广泛应用于云数据安全领域。例如文献[13]提
出基于雾计算的CP-ABE 方案，通过外包加密计算降低
终端负载，但未考虑属性维度优化。文献[14]结合区块
链实现了CP-ABE 的属性撤销，但属性筛选依赖人工定
义，难以适应大模型动态变化的属性空间。因此，现有
方案大多是假设属性集合为原始输入，并未对属性进行
语义层面的优化处理。
1.2　集成学习
集成学习技术是机器学习领域的一个重要组成部
分[15-16]，通过组合多个学习器的预测结果，多模型协作可
提升分类与特征筛选能力，集成学习能够显著降低模型
的预测误差，提高整体模型的预测性能，表现出更强的泛
化能力。另外，由于集成学习结合了多个学习器的预测结
果，因此可以降低单个学习器的过拟合风险以及预测结果
的不确定性，进而提高模型的稳定性。例如文献[17]利用
GMDH、KNN 及SVM 的集成模型筛选智能建筑数据的关
键属性，将特征数量减少40% 以上，验证了集成学习在
属性降维中的有效性。而文献[18-19]结合K-means 与
Dragonfly 算法优化特征子集，但其应用场景局限于入侵
检测，并不适用于云平台等大数据共享的场景。
大模型网络通信系统中涉及海量交互数据，这些数
据包含多种类型属性，需要通过多点传输、远程交互和
共享来满足应用需求。然而，现有安全策略在保护这些
频繁交互的大规模数据时仍存在诸多缺陷，未与加密技
术结合。因此当前已有的方法缺乏集成学习与CP-ABE
的融合设计，无法解决大模型平台属性加密的效率问题。
属性加密技术作为一种有效的细粒度访问控制手
段，能够根据用户属性动态调整访问权限，为数据安全

2　系统架构与核心算法设计
本文将融合集成学习和基于密文的属性加密技术
的优点，设计一种基于属性加密的大模型平台访问安全
控制策略，通过改进加密通信技术并结合分布式云计
算，形成对大模型云平台的安全保护机制。
2.1　系统架构
本文系统的整体流程架构如图1 所示。
系统包含以下4 个核心模块。
1） 属性数据预处理模块：利用集成学习模型对大
模型交互数据的原始属性进行特征筛选与语义聚合，生
成紧凑的语义属性集合。
2） CP-ABE 加密模块：基于语义属性集合构建访问
策略，对数据进行CP-ABE 加密，并将密文上传至云端。
3） 分布式解密模块：云节点根据自身属性集合与
密文的访问策略进行匹配，通过属性私钥解密密文。
4） 安全管理模块：负责密钥分发、属性撤销及安全
审计。
2.2　集成学习驱动的属性优化算法
2.2.1　算法核心思路
本文算法通过“特征筛选、语义聚合、策略映射”
3 层处理，将原始高维属性转换为适合CP-ABE 的低维
语义属性集合，具体如下。
1） 特征筛选是通过利用蜻蜓优化算法（Dragonfly 
Optimization Algorithm, DOA）与K-means 聚类，剔除冗
余属性并保留关键特征。
2） 语义聚合是通过GMDH、KNN 与SVM 的集成模
型降低层级原始属性。例如，可以将 “访问时间8:00—
18:00”聚合为类似于“工作时段”的高层级语义属性。
3） 策略映射则是将语义属性映射为CP-ABE 的访
问策略元素，从而降低策略复杂度。
2.2.2　算法步骤
输入：设原始属性集为n 维数据A = { a1,a2,…,an }，
此次实验中n=200，大模型交互数据集为集合D。
输出：语义属性集合Ŝ = { s1, s2,…,sm }，m ≤n，实验
中化简为45 维。
1） 数据预处理：使用K-means 聚类剔除噪声属性，
通过归一化处理属性值。
2） 特征子集优化：利用DOA 算法求解最优特征子
集R。
3） 集成学习分类与语义聚合：构建GMDH、KNN、
SVM 的集成模型，对特征子集R 进行分类训练，输出语
义属性标签。例如，可以将“用户部门=技术部”与“访问
权限=数据读写”聚合为“技术部数据操作”。
4） 属性映射与策略生成：将语义属性映射为CP-
ABE 的访问结构，例如可以将“技术部数据操作and 工
作时段”对应到访问树策略。

3　实验验证与性能分析
为验证所提基于属性加密的大模型平台访问安全
控制策略的正确性、有效性，本文设计了一套实验进行
验证与分析。
3.1　实验设置
实验设置涵盖了数据集选择、软硬件等多个方面。
其中数据集的选择尤为关键，会直接影响实验对实际场
景的模拟效果。
3.1.1　数据集
实验选用“智能金融风控大模型交互数据集”作为
实验标准数据集。该数据集专为金融领域大模型构建，
紧密围绕金融交易、用户信息及风险评估等业务场景，
与大模型平台在实际应用中的数据交互特征高度一致，
能够有效检验方案在复杂现实场景下的性能。
该数据集中包含了10 万条数据记录，数据规模达
50 GB。每条记录涵盖200 个维度的原始属性，其维度
划分遵循“业务场景-数据类型-属性颗粒度”的三层五
大类分类逻辑，具体如下。
1） 用户身份属性：包含基础身份标识（20 维，如用
户ID、身份证号）、账户信息（15 维，如注册时间、账户状
态）和机构关联（15 维，如所属金融机构、职位权限）。
这类属性用于识别用户身份，在访问控制中可作为关键
属性依据。例如，特定金融机构的高级管理人员可能具
有更高的数据访问权限。
2） 数据类型属性：涵盖交易数据（30 维，如交易类
型、金额）、用户财务数据（30 维，如年收入、资产负债
比）和风险评估数据（20 维，如信用评分、违约概率）。
不同类型的数据敏感度不同，通过对数据类型属性的分
析和加密处理，可实现对不同敏感程度数据的差异化访
问控制，如贷款申请数据可能需要更严格的访问权限。
3） 访问时间属性：包括时间戳特征（20 维，如访问
年月日时分秒、工作日标识）和时间相关性特征（15 维，
如访问间隔、季节性模式）。在实际业务中，某些数据可
能只在特定时间段内允许访问，利用访问时间属性可设
置时效性的访问策略，如规定敏感的月度财务报表仅在
每月结束后的一周内可被特定人员访问。
4） 设备IP 属性：含有网络位置特征（10 维，如IP 地
址、归属地）、设备环境特征（10 维，如设备类型、操作系
统）和网络安全特征（10 维，如IP 信誉评分、VPN 使用标
识）。结合设备IP 属性，可从网络安全角度进行访问控
制，例如限制来自特定安全区域IP 地址的访问，防止外
部非法IP 对平台数据的恶意访问。
5） 附加业务属性：包括合规监管属性（10 维，如反
洗钱标签、KYC 完成度）和业务定制属性（5 维，如个性
化服务标签、风险偏好）。
各类属性维度累计共200 维，全面覆盖金融风控大
模型交互场景的身份识别、数据分类、时间规律、设备安
全及业务合规等需求。
3.1.2　对比方案
为了验证本文方案的性能，实验将本文方法与传统
的CP-ABE，即直接使用原始属性构建CP-ABE，访问策
略基于原始属性的逻辑组合；以及单一分类器CP-ABE，
即使用单一KNN 算法进行属性筛选，再构建CP-ABE 方
案进行实验对比分析。
