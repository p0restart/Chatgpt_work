# 数据来源与复现说明

本包复核对象为D7六资产网络、T=10、K=6、B=0.6/1.2/1.8的静态规划，以及已保存的双向响应扰动。只做保存控制的可行性、算术与积分复算，没有启动新的最佳响应优化、修改模型或使用其他研究轨道替代本文证据。

## 原始输入与衍生数据

静态原始数据来自项目paper/work_d7/results/static。本包raw_static保留三容量各自的model.json、G_controls.json、F_controls.json、cross_attacks.json、cross_evaluation.csv，以及solver_audit.csv、optimizer_attempts.csv、quality.csv，共18个文件，均按原字节复制。逐项原路径、大小和SHA256见raw_static/source_manifest.json。

敏感性数据来自本地下载包“网络防御决策论文_最佳响应敏感性实验最终整合包_20261116.zip”。input/sensitivity_package内item_01至item_06按原字节提取；manifest.json保存原包文件名、大小和SHA256。依次为扰动可行性、攻击逐槽响应、数值审计汇总、敏感性汇总、正反距离/经验误差、进一步防御响应。该下载包没有提供完整运行脚本及逐次优化日志；不把30次优化成功的保存汇总改称本次独立验证了30次优化过程。

| 输出文件 | 内容 |
|:--|:--|
| data/complete_controls.csv | 三容量G/F共216组资产—区间记录，原始控制精度、区间起止时间及资源量 |

数据中asset、slot从1开始；历史项目部分CSV中的node、slot从0开始。表2缺项对应原node=3、slot=1，换算为论文v4、k=2。显示时保留六位小数，计算与总量使用未舍入值。图3的108行只取G，完整附件同时保留F，未进行控制插补或隐藏不利结果。

## 最小复算

在解压目录中，使用Python 3.11或以上、NumPy与Pandas运行：

~~~powershell
python scripts/data_audit.py
~~~

该命令读取本包raw_static及敏感性输入，重算并写入data。不调用SciPy优化器。原始核验为86/86通过，分类为12项静态控制可行性、54项静态目标/积分/状态复核、20项敏感性算术与固定控制复核。最大H48/H192差约6.73×10^-11。算法最多40次更新、SLSQP300次迭代等属于历史优化设置，不是该复算脚本的迭代规模。

本包还在不含原项目回退路径的临时独立副本中完成便携复算，86项均通过，记录见portable_validation.json。该复算使用本机Python 3.11.7、NumPy 1.26.4、Pandas 2.1.4。部分CSV与首轮核验的字节不完全一致，可能来自浮点末位和CSV序列化差别；不宣称跨环境逐字节相同。验证结果仍只针对保存控制，不构成独立重新优化或异机复现。

如需重绘图表，安装Matplotlib后运行：

~~~powershell
python scripts/make_figures.py
~~~

绘图使用本包CSV，输出PNG、PDF、SVG。字体以Windows的Microsoft YaHei为中文字体；其他系统需安装可用中文字体并调整字体设置。scripts/audit_panel_alignment.py为随包提供的布局核验依赖。figures/topology.png为原稿嵌入拓扑图；本包保留相应输入以便重绘流程保持同一图源。

## 论文导出

修订Markdown与references.bib为论文内容源。当前Word由md-to-word-docx 3.6.0导出，并作短表/算法防跨页和原生公式检查；需要python-docx。可按以下顺序生成：

~~~powershell
python scripts/prepare_export.py
python -m md_to_word qa/paper_export.md --format qa/format.txt -o 多资产网络防御决策论文_审计修订稿.docx --json
python scripts/polish_docx.py 多资产网络防御决策论文_审计修订稿.docx
~~~

导出后仍应使用Word检查页面；本次使用本机Word只读导出检查PDF，逐页查看。转换器的行内集合括号与花体字符在导出源中作等价表示，正文数学含义不变。主Markdown保留常规LaTeX写法，Word使用原生可编辑数学对象。

## 可支持与不能支持

能够支持：指定参数及K=6控制类下的已保存可行计划、经验分辨率下的双向控制响应、给定攻击条件下的目标比较、固定控制积分计算的一致性。

不能支持：连续控制全局Nash、均衡存在唯一性、交替算法通用收敛、参数和拓扑普遍稳健、真实网络部署效果或统计显著性。积分步长细化不等于控制网格细化，已发现偏离改善是未知全局偏离改善的下界而非上界。
