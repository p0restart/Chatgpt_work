# E5 求解算法可行性

2026-11-15。结论：可以复用现有RK4解析梯度、分块投影和原响应接口；目前尚不能给原模型的全局Nash求解保证。唯一均衡存在也不意味着任意迭代均收敛。

## 1. VI与Nash的关系

Z=U_K×A_K，F=(grad J_D,-grad J_A)。VI为F(z*)·(z-z*)≥0，对所有z∈Z。可微且域凸时，每个纯Nash都满足VI；若双方自身目标凸，VI才足以保证双方全局最优，从而等价Nash。仅平滑并不使该逆命题成立。紧凸域和连续F足以保证一个VI解，但尚未证明它是本博弈Nash，不能用VI存在性偷换纯均衡存在性。

## 2. 算法逐项判断

|方法|可用的条件性保证|当前适用状态|
|---|---|---|
|投影梯度 z+=P_Z(z-eta F(z))|F为mu强单调且L-Lipschitz，0<eta<2mu/L²给收缩|采样正曲率不能核定全域mu/L，当前无全局保证|
|外梯度 y=P_Z(z-eta F(z)), z+=P_Z(z-eta F(y))|单调Lipschitz、VI解非空、0<eta<1/L给有限维收敛|只需单调而非强单调，但仍未证明；解为Nash还需自身凸等条件|
|精确交替全局最佳响应|可证明响应映射压缩等额外条件时收敛|双方响应存在不足；攻击响应唯一也不足；防御单值/全域压缩待证|
|现有SLSQP+交替|局部约束优化及登记残差/改善诊断|本轮小规模多初值可检验实际稳定性，不给全局均衡或全局收敛定理|

投影按每槽盒[0,1]和加权容量独立进行：clip(v-lambda*w,0,upper)，lambda≥0由单调容量方程二分。原代码已实现该结构。无需重构正式求解系统；如果后续证明条件满足，可先在work_e中实现外梯度原型，现阶段不替换正式算法。

外梯度理论依据已访问[Korpelevich原文](https://cs.uwaterloo.ca/~y328yu/classics/extragrad.pdf)。普通投影步长条件由非扩张投影和||d-eta DeltaF||²≤(1-2eta mu+eta²L²)||d||²直接得到。BR压缩可利用局部隐函数公式D BR_D=-H_DD^-1 H_DA^(D)，再证明全域活跃约束下的统一敏感度；只计算候选无约束导数不够。

## 3. 误差与最优性证据

自然残差R_eta(z)=||z-P_Z(z-eta F(z))||/eta；原程序报告eta=1的∞范数。零残差精确刻画VI条件，不自动刻画非凸博弈的Nash。E3另计算可精确线性优化的g_VI(z)=max_w∈Z F(z)·(z-w)，其最大化是线性规划，不调用非凸响应优化。

若双方成本已证凸，则真实双方偏离之和≤g_VI，因每方凸性不等式给J_i(z_i,z_-i)-J_i(w_i,z_-i)≤grad_i J_i(z)·(z_i-w_i)。若F已证mu强单调且VI解为z*，则g_VI(z)≥mu||z-z*||²，故距离≤sqrt(g_VI/mu)。这两条均有未满足前提，不把本轮算出的残差当现成误差证书。

局部SLSQP找到的单方改善仅为未知全局偏离的下界。要证明epsilon-Nash，需要每方全局响应的下/上界证书，或已验证凸性后用VI gap上界；还需计入一致目标积分误差2eta_int。对B/A进一步需要精确积分/槽化误差，不能靠几个候选处的H加倍误差代替全域桥接。

## 4. 最小后续工作

先在原K6/B1.2不改参数下认证全域防御曲率或响应凸值，再认证交叉块及攻击RK4曲率。若只能证自身凸而不能证强单调，可先得存在性，放弃全局唯一主张；若只证局部强正则，可认证隔离的局部驻点/局部响应，明确不是全局Nash。完成这些之前，扩大多初值次数并不能填上证明缺口。
