# 写作术语表

2026-11-02；中文研究论文，目标期刊未指定。使用模型研究定位，不主张新求解算法。

| 统一用语       | 定义                    | 禁止混用          |
| ---------- | --------------------- | ------------- |
| 受损实例比例 x_i | 节点所代表实例组中受损实例的归一化比例   | 单台服务器被攻击概率    |
| 瞬时防御资源上限 B | 任一时刻隔离与恢复共享的资源上限    | 累计经费、现实货币     |
| 来源隔离 s_i   | 降低节点i向外传播的控制          | 直接修复受损实例      |
| 主动恢复 r_i   | 降低节点i受损比例的控制          | 只影响本地而不影响传播   |
| 直接价值 q_i   | 受损损失的权重               | 攻击成功概率        |
| 出边传播率之和    | 以传播率为边权的加权出度              | 实际下游损失、动态边际收益 |
| 分段开环计划     | 在初始时刻确定、各控制时段内保持常值的控制   | 实时反馈策略        |
| 交替局部响应候选   | 双方交替进行受约束局部优化所得策略对    | 严格Nash、全局最优   |
| 有限策略收益表核验  | 穷尽明确列出的合法策略并检查单方改善    | 原连续控制域的全局证明   |
| 局部攻击响应评价   | 固定防御，再通过多起点局部优化求攻击计划  | 最坏攻击全局保证      |
| 配置交互       | 价值位置变化对配置的影响依赖出边传播率之和的分布 | 动态优先级切换定理     |

所有“改善率”统一指防御总损失J_D的相对降低；安全损失、业务损失和行动成本另行分解。机制实验使用三组入口边权，随机种子11、22和33用于复现这三组边权。
