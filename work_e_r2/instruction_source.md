# Work E-R2 启动指令
## 基于全局最佳响应认证的近似 Nash 均衡验证

### 一、研究目标与任务定位

你担任本项目的**非零和微分博弈研究员、全局优化算法专家和数值认证专家**。

本阶段以已完成的 Work E、Work E-R1 和现有 D7/D8 项目为基础，开展独立的全局最佳响应认证实验。

本阶段不再优先研究整个博弈的均衡存在性与唯一性，而是针对已经得到的固定攻防策略组合，验证双方是否存在能够显著改善收益的单方面战略偏离。

**核心任务：为现有候选策略构造具有严格上下界的最佳响应证书，争取证明其为一个具有明确收益误差上界的近似 Nash 均衡。**

必须区分：

1. 启发式全局搜索发现的最佳已知响应。
2. 经过数学认证的全局最优收益上下界。
3. 对应的 Nash 偏离收益上界。
4. 通过严格误差认证的近似 Nash 均衡。

只有第三项和第四项完成，才能称为本阶段核心目标达成。

不得将 DE、SLSQP 或其他优化器的正常收敛直接等同于全局最优性证明。

### 四、R2-1：建立全局最佳响应认证公式

对于固定候选 \((U_0,A_0)\)，定义：

防御者：

\[
J_D^{BR}=\min_{U\in\mathcal U_K}J_D(U,A_0)
\]

攻击者：

\[
J_A^{BR}=\max_{A\in\mathcal A_K}J_A(U_0,A)
\]

对应 Nash 偏离收益：

\[
\Delta_D=J_D(U_0,A_0)-J_D^{BR}
\]

\[
\Delta_A=J_A^{BR}-J_A(U_0,A_0)
\]

本阶段必须分别建立：

**防御最优值的有效下界：**

\[
L_D\leq J_D^{BR}
\]

因此：

\[
\boxed{
\Delta_D\leq J_D(U_0,A_0)-L_D
}
\]

**攻击最优值的有效上界：**

\[
J_A^{BR}\leq U_A^{bound}
\]

因此：

\[
\boxed{
\Delta_A\leq U_A^{bound}-J_A(U_0,A_0)
}
\]

这些上界必须包含目标函数计算误差、数值认证误差及适用的算术误差。

启发式优化只能改善当前已知可行解，不能代替上述下界或上界证书。

将认证结果统一记录为：

\[
0\leq\Delta_D\leq\epsilon_D
\]

\[
0\leq\Delta_A\leq\epsilon_A
\]

若两项均完成，即可证明固定候选是一个 \((\epsilon_D,\epsilon_A)\)-Nash 均衡。

### 五、R2-2：攻击者全局最佳响应认证

**优先执行，作为第一项需要完成的独立认证。**

E-R1 已证明精确 ODE 模型中的攻击者收益具有强凹性：

\[
-\nabla^2_{AA}J_A^B
\succeq\frac53 I
\]

因此，固定防御策略 \(U_0\) 后，攻击者的优化问题具有唯一全局最佳响应。

#### 任务1：建立攻击收益梯度认证

计算：

\[
\nabla_AJ_A^B(U_0,A_0)
\]

优先使用已有状态灵敏度方程或伴随方程。

需要对梯度计算误差进行认证，可使用经验证的积分方法或建立 B 与 C0 的梯度误差界。

不得直接使用未经误差验证的 C0 梯度作为 B 的精确梯度。

#### 任务2：基于强凹性构造全局上界

利用：

\[
J_A^B(U_0,A)\leq
J_A^B(U_0,A_0)
+\nabla_AJ_A^B(U_0,A_0)^T(A-A_0)
-\frac56\|A-A_0\|^2
\]

得到：

\[
\boxed{
\Delta_A^B\leq
\max_{A\in\mathcal A_K}
\left[
\nabla_AJ_A^B(U_0,A_0)^T(A-A_0)
-\frac56\|A-A_0\|^2
\right]
}
\]

这是一个带线性容量约束的凹二次最大化问题，等价于凸二次最小化问题。

对其求解并形成可独立验证的全局上界证书。

若梯度采用区间表示，必须将梯度不确定性纳入上界。

可以使用原始—对偶最优性证书、经验证的 KKT 条件或其他可靠方法。

同时计算较保守但易验证的线性最佳响应上界作为交叉核查。

#### 任务3：验证攻击者全局最佳响应

可运行多起点 SLSQP 或其他优化器寻找全局最佳响应候选，但其作用仅限于提供可行最优值和检查认证界的紧度。

输出：

- 攻击者最佳已知响应。
- 已认证的全局最优收益上界。
- 攻击者偏离收益上界。
- 与原有 VI gap 的差异。
- 认证所依赖的模型对象和误差控制。

**第一阶段验收：取得攻击者在 B 或 C0 中的严格全局偏离收益上界。**

`R2_01_attacker_global_response.md`

### 六、R2-3：防御者全局最佳响应搜索

**这是本阶段计算难度最大的任务。**

固定攻击策略：

\[
A=A_0
\]

求解：

\[
\min_{U\in\mathcal U_K}J_D(U,A_0)
\]

防御策略共72维，且原模型尚未证明全域凸性。

因此，不得采用“单次 SLSQP 求解成功”作为全局最优性证明。

#### 任务1：先寻找最佳已知可行防御策略

复用原有 SLSQP 求解接口。

在其基础上可使用：

- 多初值 SLSQP。
- 差分进化 DE。
- 分块全局搜索与局部精修。
- 其他不改变原目标函数的优化方法。

搜索期间严格满足逐槽防御容量约束。

对全部可行候选计算防御成本。

记录最优已知可行值：

\[
J_D^{UB}
\]

由于这是最小化问题：

\[
J_D^{BR}\leq J_D^{UB}
\]

这里的上界只用于寻找改进策略和提高后续分支定界效率。

**它不能证明原候选的 Nash 偏离误差很小。**

若发现显著优于 \(U_0\) 的防御响应，应记录该事实，不得偷偷更换原候选使 gap 重新变小。

#### 任务2：构造防御最优收益的全局下界

优先研究以下认证方法：

**方法A：结构化目标下界。**

利用状态非负、资产传播 DAG、二次防御成本和逐槽预算约束，为包含一定范围防御策略的子区域计算严格目标下界。

应当保留与原始状态演化一致的时间传播关系，不能直接将状态变量与控制变量当作彼此独立而得到错误界。

可以使用可靠的区间状态传播或微分不等式构建安全包络。

**方法B：利用 E-R1 的弱凸性下界。**

E-R1 已证明精确 ODE 模型中：

\[
\nabla^2_{UU}J_D^B\succeq-65I
\]

因此，对于任意可行参考策略 \(U_c\)，可以使用：

\[
J_D^B(U,A_0)\geq
J_D^B(U_c,A_0)
+\nabla_UJ_D^B(U_c,A_0)^T(U-U_c)
-\frac{65}{2}\|U-U_c\|^2
\]

作为全域有效的二次下界。

将其用于逐步缩小的策略子区域，并通过线性规划或有认证的界计算获得每个子区域的目标下界。

必须包含函数值和梯度的数值认证误差。

初始全域界可能十分宽松。需要通过分区与结构信息缩紧，不得直接将宽松界称为完成认证。

**方法C：其他可验证的全局下界技术。**

允许采用区间分支定界、经过验证的凸松弛或其他具有数学上下界保证的方法。

所有下界方法必须能够独立复核。

#### 任务3：建立全局分支定界流程

将完整72维防御可行域划分为若干子区域。

对每个子区域：

1. 判断其是否与原始容量可行域相交。
2. 计算可靠目标函数下界。
3. 利用当前最佳可行防御收益上界进行剪枝。
4. 对尚不能剪枝的区域继续细分。
5. 在全部区域被认证覆盖的前提下，得到全局最优值下界。

分支应优先考虑对状态和收益影响较大的控制维度，而不是简单地对72维变量进行均匀网格划分。

可以利用 DAG 传播路径、时间分段结构和资源容量约束减少无效分支。

每次剪枝必须保留可检查的数学依据。

不得将未搜索区域直接视为无更优解。

#### 任务4：形成全局偏离上界

设认证得到：

\[
L_D^{cert}\leq\min_UJ_D(U,A_0)
\]

则：

\[
\boxed{
\Delta_D\leq J_D(U_0,A_0)-L_D^{cert}
}
\]

记录该上界随分支数量和计算成本的变化。

如果未得到足够紧的下界，必须明确说明未完成认证。

### 八、R2-5：近似 Nash 均衡判定

采用双方最大单边收益改善量作为评价指标。

定义：

\[
\epsilon=\max(\epsilon_D,\epsilon_A)
\]

同时报告两个分别归一化的指标：

\[
\bar\epsilon_D=
\frac{\epsilon_D}{1+|J_D(U_0,A_0)|}
\]

\[
\bar\epsilon_A=
\frac{\epsilon_A}{1+|J_A(U_0,A_0)|}
\]

原始收益误差与归一化误差必须同时保留。

### 预设实验目标

优先争取：

\[
\bar\epsilon_D\leq 1\%
\]

\[
\bar\epsilon_A\leq 1\%
\]

如果计算成本允许，进一步尝试0.1%的归一化目标。

1%仅是本次预实验的工程验收目标，不是数学上 Nash 均衡的统一阈值，也不是允许放宽严格认证标准的理由。

必须报告认证得到的实际 \(\epsilon_D,\epsilon_A\)，而不是把预设1%当成最终结果。

若只能认证攻击者一侧，不得声称联合策略已获得近似 Nash 均衡认证。

如果发现任一方存在明显有利偏离，必须将其列为原候选策略的反证性实验发现，并记录具体改进幅度。

### 九、R2-6：计算预算与停止条件

为了避免在72维空间进行不可控的全局分支搜索，采用分阶段执行。

**阶段一：认证准备。**

完成原始数据校验、候选冻结、双方最优值界定义和基础误差核查。

**阶段二：攻击者认证。**

优先完成12维攻击者全局偏离上界证书。

**阶段三：防御者试运行。**

先进行小规模、带上下界记录的分支定界试验。

初始分支预算建议不超过2,000个子区域，评估：

- 目标下界是否有效。
- 剪枝率。
- 全局上下界收缩幅度。
- 单位计算成本带来的认证精度改善。

**阶段四：有条件扩展。**

只有在下界确实持续收紧、算法具有可复核的全域覆盖逻辑时，才扩大至例如30,000个子区域的试验预算。

如果下界长期停滞，应分析松弛过宽的原因并停止扩大规模。

不得仅为完成认证目标无限增加随机种子、局部优化次数或分支数量。

允许提前完成部分成果；但不得将未认证的结果标记为成功。

### 十一、最终验收标准

本阶段最重要的不是取得更大的防御收益，而是确定原有博弈解是否经得起全局战略偏离检验。

结果分为四种：

**A：完整认证成功。**

攻防双方的全局偏离收益均有严格上界，且满足预设1%目标。

可以表述为具有明确误差保证的近似 Nash 均衡策略。

但不能据此宣称精确 Nash 均衡存在或唯一。

**B：部分认证成功。**

攻击者取得严格上界，防御者暂未取得足够紧的全局下界。

保留单侧认证结果，不得将其表述为联合近似均衡。

**C：发现显著战略偏离。**

至少一方找到明显优于原策略的可行响应。

说明原候选在相应误差目标下不满足 Nash 条件，需要后续重新求解与验证，但本阶段不能擅自覆盖原候选。

**D：认证方法计算成本过高。**

保存所有有效上下界和计算记录，明确说明当前算法与计算资源下尚不能完成认证。

不得将“未完成认证”解释为“均衡不存在”。
